# Shadowrocket 配置选择指南

## 快速推荐

| 场景 | 推荐配置 | 文件 |
|------|---------|------|
| **大多数人（推荐）** | 黑名单 + 去广告 | `sr_top500_banlist_ad.conf` |
| 怕漏代理 | 白名单 + 去广告 | `sr_top500_whitelist_ad.conf` |
| 懒人一键用 | 懒人配置（策略组） | `lazy_group.conf` |

---

## 核心区别：黑名单 vs 白名单 vs 国内外划分

```
                    被墙网站    未知网站    中国网站
黑名单 (banlist)     代理        直连       直连
白名单 (whitelist)   代理        代理       直连
国内外划分 (cnip)    代理        代理       直连
```

- **黑名单**：只有 GFWList 里的网站走代理，其余直连 → **省流量，速度快，偶尔漏**
- **白名单**：只有已知能直连的走直连，其余全代理 → **不漏，但费流量**
- **国内外划分**：按 IP 地理位置分流 → **中间方案，靠 GEOIP 判断**

白名单和国内外划分的核心区别：白名单额外把 top500 可直连的境外网站设为直连，国内外划分则纯靠 `GEOIP,CN` 判断。

---

## 去广告 vs 不去广告

带 `_ad` 后缀的包含广告过滤（~64000 条规则，其中 ~240 条手工 Reject + ~63800 条自动生成），不带的只做分流。SR 作者说过规则数量不影响性能（O(1) 查找），所以**建议选带去广告的版本**。

---

## 关键区别速查

| | 未知网站 | 中国网站 | GFWList | 去广告 |
|---|---|---|---|---|
| **黑名单** | 直连 | 直连 | 代理 | 可选 |
| **白名单** | **代理** | 直连 | 代理 | 可选 |
| **国内外划分** | **代理** | 直连 | 代理 | 可选 |
| **回国** | 直连 | **代理** | — | 可选 |
| **全局直连** | 直连 | 直连 | — | 有 |
| **全局代理** | **代理** | **代理** | — | 有 |

## 各配置匹配顺序（规则从上到下匹配，命中即停）

### 1. `sr_top500_banlist_ad` — 黑名单 + 去广告

```
1. 389 条手工代理域名                    → Proxy（Telegram、TED、GFW 常见站点等）
2. ~64000 条广告域名                     → Reject（广告拦截）
3. ~28000 条 GFWList 被墙域名            → Proxy（自动生成的 GFW 列表）
4. Apple News RULE-SET                   → Proxy
5. FINAL                                 → direct（其余全部直连）
```

```

```

### 12. `sr_adb` — 黑名单 + 去广告 + top500 分流

```
1. ~240 条手工 Reject 域名               → Reject

3. ~100 条手工直连域名（Apple CDN 等）    → Direct
4. ~63800 条广告域名                     → Reject（广告拦截）
5. ~220 条 top500 需代理的境外网站        → Proxy（Google、YouTube 等）

7. FINAL                                 → direct（其余全部直连）
```

### 13. `lazy` — 懒人配置

```
独立完整配置，自带 [General] DNS/TUN 等设置
来自 LOWERTOP/Shadowrocket 维护，国内外划分逻辑
中国网站                                 → 直连
其余                                     → 代理
```

### 14. `lazy_group` — 懒人配置（策略组）

```
同 lazy，额外支持策略组（可按节点分组选择代理线路）
中国网站                                 → 直连
其余                                     → 代理（可选策略组）
```

## 特殊用途

| 配置 | 适合谁 |
|------|--------|
| `sr_direct_banad` | 不翻墙，只想全局去广告 |
| `sr_proxy_banad` | 全部流量走代理 + 去广告 |
| `sr_backcn` / `sr_backcn_ad` | 海外华人，想访问国内网站 |
| `sr_ad_only` | 纯广告过滤，不做任何分流 |
| `lazy.conf` / `lazy_group.conf` | 开箱即用，含完整 DNS 配置 |

## lazy 和其他配置的区别

`lazy` 系列是**完整独立配置**，自带 DNS、跳过代理、TUN 等 `[General]` 段配置，适合新手。其他 `sr_*` 系列的 `[General]` 段较精简，更适合有经验的用户。

---

## 推荐

- **日常使用**：`sr_top500_banlist_ad.conf`（黑名单 + 去广告，绝大部分人够用）
- **对隐私/访问要求高**：`sr_cnip_ad.conf`（国内外划分 + 去广告，不会漏）
- **需要 Apple Intelligence / iCloud Private Relay / Microsoft 全局代理**：选对应的 `_plus` 后缀版本（如 `sr_cnip_ad_plus.conf`）
- **新手/不想折腾**：`lazy_group.conf`（懒人配置，开箱即用）
